# Exercices Python - Parcours AFE (TgMaster University)

Espace **étudiant**. Tu y trouves les notebooks à exécuter et les applications d'exercices
auto-corrigées. (Les corrigés ne sont pas ici : ils sont réservés aux enseignants.)

## Notebooks (à exécuter dans Google Colab)

- `notebooks/Cours_02_Regression.ipynb` - régression linéaire (M2 vs inflation).
- `notebooks/Cours_10_Backtest/notebook_backtest.ipynb` - backtest momentum sur la BRVM.

Ouvre chaque notebook et clique sur le badge **« Ouvrir dans Colab »** en haut : il s'exécute
gratuitement dans ton navigateur, sans rien installer.

## Applications d'exercices (dans le navigateur)

Les apps `apps/Cours_XX_.../` te font écrire du Python et vérifient automatiquement tes réponses.
Elles s'ouvrent directement dans le navigateur (lien fourni dans Moodle). Ce sont des exercices
d'entraînement : aucune note n'est enregistrée.
