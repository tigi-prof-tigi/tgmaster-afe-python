## Applications d'exercices (dans le navigateur)

Les apps `apps/Cours_XX_.../` te font écrire du Python et vérifient automatiquement tes réponses.
Elles s'ouvrent directement dans le navigateur (lien fourni dans Moodle). Ce sont des exercices
d'entraînement : aucune note n'est enregistrée. Le bouton « Voir la solution » est volontaire
(auto-correction) : ces apps sont formatives, la note réelle reste l'examen et les tests Moodle.

Depuis chaque app, le bouton **« Accueil »** (en haut à droite) ramène au portail.
